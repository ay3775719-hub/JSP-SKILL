# 音效与 BGM

## 音效从哪来

- 用户自己的音效库优先；没有就去 Pixabay 等免费可商用的网站下（下之前看授权），放进库的 `sfx/`。
- 每个音效测一次「最响的那一下在第几帧」，记进 `sfx/peaks.json`：
  ```bash
  ffmpeg -i sfx/pop.mp3 -af astats=metadata=1:reset=1,ametadata=print:key=lavfi.astats.Overall.Peak_level -f null - 2>&1 | grep Peak_level
  ```
  （或者让 AI 用 Python 读波形找最大值所在帧。）

## 对齐：按峰值，不按文件开头

音效文件开头常有一段起音或空白，从文件开头对齐就会比画面晚。

**片段起点 = 画面动作发生的帧 − 文件到峰值的帧数。**

- 滑动 whoosh：峰值压在滑动最快的那几帧。
- 落定、撞击：峰值对齐落定那一帧。
- 划线：声音和画面上的线同时起。
- 打字：每出一个字一声键盘声，字和声音同一帧。
- 一段里两个动作挨得太近（< 3 帧）合成一声。

## 音量（片段增益参考）

口播峰值约 -5 dBFS 时，这些增益听起来刚好（不同文件响度不一样，以实际听为准）：

| 音效 | 片段增益 | 什么时候用 |
|---|---|---|
| pop（轻） | -3 左右，要突出的 +3 | 标签、卡片、关键词出现 |
| whoosh（柔） | -4 左右 | 版式滑动、口播移位、大字出现 |
| whoosh（重） | -2 ～ +2 | 放大打点、重的滑动 |
| impact | -3 | 大标题落下、最重要的一句（比如「开源」） |
| 铅笔划线 | -5 | 划线、圈画、黄条刷出 |
| 键盘单键 | -20 左右 | 打字 |
| 鼠标单击 | -10 | 点按钮 |

不要把「目标峰值 -26 dB」这种数直接填成片段增益，那样会小 15–20 dB，根本听不见。

**规矩**：
- 一个动作只配一声；**画面上没有对应动作就不配**。
- 刺耳的「叮」、shimmer、嘶声少用。
- 放完整体峰值不超过约 -1 dBFS；音效叠在口播和 BGM 上时容易冲高，冲高就降那一声。
- **要实际听过才算检查过**。

## BGM

- 片头一定要有 BGM，开头要有节奏上的顿挫，能和片头剪辑点、标题落下卡在一起。先给用户 2–3 首候选（试听时间点 + 为什么适合）。
- 进正片后 BGM 在口播下面 15–20 dB，听得见、不抢话。
- 章节卡、大转折处 BGM 断开约 1 秒再接回。
- 放成片原声时 BGM 让开，原声过后可以从曲子开头重新起一次。
- **结尾段落把 BGM 拉起来**：最后一两句话 BGM 换一首或从高潮处起、音量抬高，把结尾的情绪做出来。
