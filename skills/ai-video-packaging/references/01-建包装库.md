# 建包装库

目标：一个文件夹里放着用户**审过的**包装，每个包装有编号、预览、能改字改时间的模板，和一句「什么时候用」。以后剪片只从这里拿。

## 库的结构

```
我的包装库/
  目录.md                ← 场景 → 编号表 + 编号总表（tools/catalog.py 生成，别手改编号总表那段）
  cases/
    C01_小标题入场/
      case.json          ← 编号、名字、分类、什么时候用、怎么改、音效、来源、状态
      effect.html        ← 复刻稿：window.META + window.render(t)
      preview.mp4        ← 渲出来的预览（tools/render.mjs --preview）
      ref.mp4            ← 参考样片里的那一段（可选）
  effects/lib.js         ← 所有复刻稿共用：缓动、建元素、帧序列
  fonts/                 ← 用到的字体文件（思源黑体、阿里普惠体等免费可商用字体）
  sfx/                   ← 音效文件 + peaks.json（每个音效最响的那一帧）
  tools/                 ← render.mjs / preview.mjs / catalog.py / cut_check.py
```

## 分类和编号

| 前缀 | 分类 | 例子 |
|---|---|---|
| L | 组合界面（口播和素材怎么排） | 左素材右口播、录屏铺满 + 右下圆头像、透视卡片 |
| BG | 动态背景 | 胶片划痕黑底、浅色柔光底 |
| T | 大标题 / 大字 | 人像后大字逐字上滑、两侧大字 |
| C | 小标题 / 关键词 | 左上小标题、黄色划线标签、荧光标签左右分列、玻璃胶囊 |
| E | 解释元素 | 问题框打字、四角黑场金句、前后对比划像、数字对比 |
| S | 字幕 | 常规字幕、电影感字幕 |
| R | 待入库（复刻中） | 评审通过后改成上面的正式编号 |

编号一旦入库就不再改；同类的往后排（C01、C02…）。

## 第一步：收样片、拆包装

1. 让用户给 3–5 条最喜欢的视频（自己往期的最好，其次是对标博主），或者直接指着某一段说「这个我要」。
2. 逐段看（可以用 ffmpeg 每秒抽一帧拼成联系表），每个包装记一行：

   | 时间 | 口播在讲什么 | 画面怎么动 | 声音 | 建议分类 |
   |---|---|---|---|---|
   | 0:12 | 抛出一个数字 | 白色大字在人物身后逐字从下往上滑 | 一声 whoosh | T |

3. 把**「口播在讲什么」**那一列当成以后选包装的依据，写进 `case.json` 的 `when`。这一列比「长什么样」重要：用库的时候 AI 是按场景找包装的。
4. 先问用户：哪些要复刻、哪些不要。别一口气全做。

## 第二步：写复刻稿

每个包装一个 `effect.html`，规矩：

- 画布 1920×1080（渲染时按 2 倍出 4K），背景透明；需要底下垫口播画面的版式，用 `seqImg` 把口播帧序列画进页面里（这样口播也能缩放、移动、进画框），渲成不透明的。
- 页面提供：
  ```js
  window.META = {dur: 3.0, sfx: [['pop', 0.10], ['whoosh', 0.45]]};  // 时长（秒）、音效（名字, 动作发生的秒）
  window.render = (t) => { ... };                                      // 给定第 t 秒，把画面摆成那一刻的样子
  ```
- **所有动画都是 t 的函数**，不用 CSS 动画 / setTimeout（逐帧截图时才能每一帧都准）。
- 开头要改的东西集中写成参数块（文字、开始帧、位置），模板复用时只改这一块：
  ```js
  const TPL = {text: '第一步：搭框架', start: 0.3, x: 72, y: 840};
  ```
- 硬切进来的版式**第 0 帧就满不透明**，不要淡入（淡入会在剪辑点露出一两帧半透明）。
- 有分量的字落定不回弹（用 out-expo），回弹会显得卡通。
- 示例：`cases/C01_小标题入场/effect.html`。

## 第三步：渲预览、对样片

```bash
cd 我的包装库/tools
node render.mjs ../cases/C01_小标题入场/effect.html --preview        # → 同文件夹 preview.mp4（带底色，方便看）
node preview.mjs ../cases/C01_小标题入场/effect.html 0.2 0.6 1.5       # 单独截几帧看
```

和样片**同一时刻**的帧并排比：位置、字号、颜色、节奏（几帧出完）、落定方式。差得多就接着改，不要把「差不多」的给用户。

## 第四步：评审、入库

1. 把预览发给用户，问「要 / 改 / 不要」。
2. **要**：改正式编号（文件夹 `R03_xxx` → `C05_xxx`，`case.json` 里的 `id`、`status: "入库"`），补全 `when` / `how` / `sfx`。
3. **改**：按意见改 → 重渲 → 再给看。用户说「挪到哪里」就在模板里改坐标，不要猜。
4. **不要**：`status: "不要"`（`catalog.py` 不会列出来），文件留着不删。
5. 跑 `python3 tools/catalog.py`，`目录.md` 自动更新编号总表；**「场景 → 编号」表**手动补一行（这张表是用库时最先查的）。

## case.json 写法

```json
{
  "id": "C01",
  "name": "小标题入场",
  "section": "C",
  "status": "入库",
  "when": "每个组合界面左上角的小标题；口播讲到一个新的小节",
  "how": "改 TPL.text；TPL.start 是竖条开始画的秒数；位置默认左上 (108, 96)",
  "sfx": "不配音效（版式硬切进来时不配）；要配就用 pencil，峰值对竖条画完那一帧",
  "source": "参考：自己 2026-05 那期 0:05",
  "transparent": true
}
```

## 常用包装从哪开始建

第一次建库，建议先做这 8 个，覆盖大部分口播视频：

1. C 左上小标题（每个组合界面都要）
2. C 黄色划线 / 荧光标签（关键词、数字）
3. T 人像后大字（一个数字或关键词砸出来）
4. L 左素材右口播（边讲边展示成片 / 图片）
5. L 录屏铺满 + 右下圆头像（软件实操）
6. E 四角黑场 + 重点字变色（一句金句）
7. 章节卡（黑底 + 小签 + 大标题）
8. S 字幕样式
