# 版式、构图与节奏

这些是大象学长团队⁠​‌​​​‌​​​‌​‌‌​​​​‌​‌‌​​​​‌​‌‌​‌​​​‌​‌‌​‌​‌​​​​​‌​‌​‌​‌‌​​‌​‌​​​​​​‌​‌‌​‌​​‌‌​​‌​​​‌‌​​​​​​‌‌​​‌​​​‌‌​‌‌​​​‌‌​​​‌​​‌‌​​​​​​‌‌​​‌​​​‌‌‌​​‌​​‌​‌‌​‌​‌​‌​‌‌​​​‌‌​​​‌⁠一期一期被点评、改出来的规矩。坐标都是 1920×1080 设计尺寸（4K 乘 2）。

## 构图

- **中下方永远留给字幕**（大约 y 900 以下、x 400–1520）。包装文字放左上、上方或人物两侧。
- **字不挡脸、不挡耳朵**：人物两侧的字和头至少留 30–40 px；放不下就把口播放大往一边移，把另一边让出来（见下面「口播放大左移 / 右移」）。
- **口播头像窗**：眼睛在窗口的上三分之一线；不要头在正中间、头顶空一大块；口播画面要盖满窗口，窗口顶上不能露底色。
- **圆头像**：直径约 340 px，右下角（中心约 1680, 846），白边 6 px + 投影。
- **并排的框上下沿对齐**；头像框下沿和文档框下沿对齐。
- 第一次就放对位置，别等用户挪；用户挪过的位置，以后同类包装直接照用。

## 常用版式尺寸

| 版式 | 做法 |
|---|---|
| 录屏实操 | 录屏铺到画面 90–95%（圆角 + 投影），右下圆头像**压在录屏上面**；左上一个醒目的标签；录屏先裁掉菜单栏、Dock，只留软件窗口 |
| 左素材右口播 | 左边 16:9 内容框 x=108, y=240, 1148×646；右边口播窗 x=1329, y=240, 480×644 |
| 口播放大左移 / 右移 | 口播放大 1.3 倍、平移 280 px（平移 ≤ (放大 − 1) × 1920 / 2，否则露边），让出的那一侧压一层深色渐变，字和图标都放那一侧 |
| 放大打点 | 平的口播段放大 1.18 倍硬切进、约 3 秒，落在一个新观点的开头 |
| 章节卡 | 黑底（胶片划痕）+ 黄色小签「第一章」+ 白色大标题；口播在这里断开约 2 秒，BGM 一起断 |

## 节奏

- **一个版式管一整段**：从段落开头管到段落讲完，在下一段的剪辑点切回。结束点离剪辑点不到 1 秒的，延到剪辑点。
- **呼吸感**：上一个镜头刚做完缩放动画，下一个不要马上再动，直接硬切；进一个版式先停 1.5–2 秒再做下一个变化。不是每秒都要变。
- **接成片 / 章节卡前不缩回**：放大保持到切点直接切。
- 有动画的进场（缩小成头像、口播移位）配一声 whoosh；**硬切进来的版式不配音效**。

## 文字

- **不要逐字跳出 / 打字机式写出**（显得廉价）。要逐字出场，用逐字上滑：每个字在遮罩里从下往上滑，14 帧 expo，字间隔 2–3 帧，整组只配一声。
- 有分量的字落定不回弹。
- 高亮 / 划线只盖重点词，不盖标点。
- **同层级的信息用同一样式同一大小**（例如「2400 次工具调用」和「500 次脚本」是并列的两个数，就做成一模一样的两组）。
- 左右对称的大字，左右长短尽量一样（字号自动算到同宽）。
- 只提炼关键词或数字，不把整句话做成字幕切片。
- 需要停留的信息停到这一段结束；多张卡片一张一张出，不要 1 秒内堆满。

## 素材

- 讲「AI 帮我做了 X」：放**真实录屏 / 真实对话截图**，不做假的。
- 口播一直在讲、画面放 B-roll 时，加上圆头像，别让人整段消失。
- 放别人的成片就放成片原声，BGM 让开。
- 用网上的素材左上标「素材来源于互联网」。
- 提到软件 / 平台时，可以出它的真 Logo（带一点 3D 侧角和柔光），不要用文字代替；Logo 一直留到这段讲完。

## 首尾帧

切点前后 1–3 帧最容易出问题：少效果、跳一下、半透明叠影。
1. 动画稿第 0 帧满不透明，不淡入。
2. 包装片段的头尾和口播剪辑点对齐到帧。
3. 24fps 的素材放进 30fps 时间线，入点可能带上一个镜头的尾巴，逐帧看。
4. 每次渲完跑 `tools/cut_check.py`，标出来的逐帧看。
