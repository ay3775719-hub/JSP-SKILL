# 用库剪一期

前提：口播已经剪好（或用户给了定稿口播稿 + 剪好的口播时间线），包装库里有入库的包装。

## 1. 读稿、切段

- 读用户定稿的口播稿，再对照时间线上实际说的话（以实际说的为准）。
- 按「一个意思一段」切开，记下每段在时间线上的起止帧（30fps 时间线按帧记，别按秒估）。

## 2. 出包装清单（必须用户确认）

先读库里 `目录.md` 的「场景 → 编号」表，每段挑一个；挑不到的写「建议新做」。清单格式：

| 时间 | 口播 | 编号 | 改什么 | 音效 |
|---|---|---|---|---|
| 00:08–00:13 | 一共调用了约 2400 次工具 | T03 人像后大字 | 文字「2400 次」；第 0.2 秒开始 | whoosh 峰值对第一个字落定 |
| 00:36–00:39 | 三连打卡我们开始上课 | C08 | … | pop ×3 |

规矩：
- 一个版式管一整段，到下一段剪辑点才切回。
- 同一种版式一期里尽量不重复（除了小标题、字幕这种每段都有的）。
- 平的口播段每隔一会儿打一个点（放大 1.18 倍硬切，约 3 秒），不要整段一成不变；也不要每秒都在动。

**用户确认清单之前不往时间线上放东西。**

## 3. 出素材

1. 在项目里建 `动画稿/`，把对应编号的 `effect.html` 复制进来，改名成「时间_编号_内容.html」。
2. 只改参数块（字、开始时间、位置），**不改动画本身**——要改动画说明这个包装该升级了，回库里改、重新评审。
3. 渲染：
   ```bash
   node 我的包装库/tools/render.mjs 动画稿/0008_T03_2400次.html 包装成品层/0008_T03_2400次.mov
   ```
   透明的出 ProRes 4444（带 alpha）；自带口播画面的出 `--opaque`（ProRes 422 HQ）。
4. 抽几帧和库里的 `preview.mp4` 对比，确认样子一致。

## 4. 上时间线

- 包装放在口播上方的轨道，**头尾压在口播剪辑点上**（差 1–2 帧就会露出没包装的画面）。
- 达芬奇可以用脚本直接放（见 `05-达芬奇脚本要点.md`）；剪映 / Premiere / Final Cut 就告诉用户：哪个文件、放第几轨、从几分几秒几帧开始。
- 音效同一步放：按 `04-音效与BGM.md` 的峰值对齐。

## 5. 交付和自查

一分钟一分钟交检查版（720p 带字幕就够），每版写清：改了哪几处、哪些验证过、哪些没有（尤其「声音还没试听」）。

自查清单：
- [ ] 每个剪辑点前后各看一帧：有没有闪、跳、缺效果（`python3 tools/cut_check.py 检查版.mp4 起始帧`）
- [ ] 字有没有挡脸、挡字幕
- [ ] 包装和口播内容对得上（说到哪个词，哪个词出来）
- [ ] 音效有对应的画面动作；没有动作的音效删掉
- [ ] 口播峰值约 -5 dBFS，整体不削波；BGM 听得见但在口播下面
- [ ] 结尾段落 BGM 起来

用户的修改意见：逐条改，改完逐条回复「改了什么、在哪看」。同类的意见以后第一次就做对——把它写进库里这个包装的 `case.json` 的 `how`。
