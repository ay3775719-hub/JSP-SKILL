# 用脚本操作达芬奇（DaVinci Resolve）

达芬奇 Studio 版可以用 Python 脚本操作（偏好设置 → 系统 → 常规 → 外部脚本使用 = 本地）。有的 AI 工具可以接达芬奇的 MCP，直接跑脚本。剪映 / Premiere 用户跳过这一页，按包装清单手动拖。

## 放素材

```python
mp = project.GetMediaPool()
tl = project.GetCurrentTimeline()
s = tl.GetStartFrame()                      # 时间线起点（通常 01:00:00:00 = 108000 帧 @30fps）
item = mp.ImportMedia(['/path/包装成品层/0008_T03_2400次.mov'])[0]
mp.AppendToTimeline([{'mediaPoolItem': item, 'startFrame': 0, 'endFrame': 150,
                      'trackIndex': 5, 'recordFrame': s + 240, 'mediaType': 1}])
```

坑：
- **`endFrame` 不包含**：要 150 帧就写 `endFrame: 150`，写 149 会少一帧，包装提前一帧消失。
- 音频片段的 `startFrame / endFrame` 单位跟着音频文件走，可能和时间线帧数对不上；放完读一下 `GetStart() / GetEnd()` 核对长度。
- 目标位置已经有片段时，`AppendToTimeline` 可能悄悄放到别的位置或返回一个空片段（`GetStart()` 是 None）：放之前先查轨道空不空，放之后核对位置。
- 改之前先确认当前时间线是不是你要改的那条（`tl.GetName()`），最好在复制出来的时间线上改。

## 改属性

```python
item.SetProperty('ZoomX', 1.18); item.SetProperty('ZoomY', 1.18)   # 静态缩放
item.SetProperty('Pan', -280)                                       # 平移
item.SetProperty('AudioVolume', -3.1)                               # 片段增益（dB）
item.SetClipColor('Yellow')
```

- 剪辑页的**关键帧没有脚本接口**：要动画就用 Fusion，或者在 HTML 里做好渲成视频。
- **24fps 的「调整片段」放在 30fps 时间线上做放大，开头会有 2–3 帧慢慢放大上去**（看起来像没切干净）。直接在口播片段上 `SetProperty` 放大最干净。
- 颜色：HTML 里画的口播帧是没调色的原素材，和时间线上调过色的口播会有色差。在这个版式片段上加一个校色节点（`item.SetCDL({...})`）对齐。

## 字幕

- 字幕片段的文字脚本改不了。做法：导出 DRT → 改里面的字幕 → 再导入；或者生成 SRT 拖进字幕轨。
- 渲检查版时 `ExportSubtitle: True, SubtitleFormat: 'BurnIn'` 把字幕烧进去。

## 渲染检查版

```python
project.SetCurrentRenderFormatAndCodec('mp4', 'H264')
project.SetRenderSettings({'SelectAllFrames': False, 'MarkIn': s + 0, 'MarkOut': s + 470,
    'TargetDir': '/path/工具', 'CustomName': '检查_开场',
    'FormatWidth': 1280, 'FormatHeight': 720, 'ExportSubtitle': True, 'SubtitleFormat': 'BurnIn'})
jid = project.AddRenderJob(); project.StartRendering([jid])
```

- `SetTrackEnable(False)` 关掉的轨道渲染时不一定被排除，别指望用它出「只有口播」的版本。
- 渲完跑 `tools/cut_check.py 检查_开场.mp4 0`。
