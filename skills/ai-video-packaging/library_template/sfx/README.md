# 音效

把常用音效放这里，文件名（不带扩展名）就是音效名，复刻稿 `META.sfx` 里用这个名字，比如 `['pencil', 0.3]`。

`peaks.json` 记每个音效最响的那一下在第几帧（30fps），以及预览时的音量：
```json
{"pencil": {"peak_frame": 4, "gain_db": -5}}
```
`render.mjs --preview` 会按「动作秒数 − 峰值帧」把音效对齐到画面上。没有音效文件的，预览会先跳过那一声。

去哪找：自己的音效库，或 Pixabay 等免费可商用的网站（下之前看授权）。常备：pop（轻）、whoosh（柔 / 重）、impact、铅笔划线、键盘单键、鼠标单击。
