# 字体

把包装用到的字体文件放这里，`effects/lib.js` 会自动加载；没有就退回系统字体（苹方 / 微软雅黑）。

推荐免费可商用的：
- 思源黑体 Source Han Sans（Heavy、Medium）：https://github.com/adobe-fonts/source-han-sans/releases
- 阿里巴巴普惠体 3.0：https://www.alibabafonts.com/

文件名和 lib.js 里写的对上：`SourceHanSansCN-Heavy.otf`、`SourceHanSansCN-Medium.otf`、`AlibabaPuHuiTi-3-105-Heavy.ttf`。用别的字体就在 lib.js 里加一行 @font-face。
