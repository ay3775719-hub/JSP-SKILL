让你的 AI（Codex、Claude、WorkBuddy 等）帮你：

1. **搭一套你自己的包装库**：从你喜欢的视频里拆出标题、小标题、关键词、组合界面等包装，复刻成能反复用的动画模板，编号、写清楚什么场景用。
2. **剪片时自动从库里调用**：按口播内容挑包装、改字改时间、渲成透明视频放上时间线，音效按峰值对齐。

AI 不现编包装，只用你审过的库，所以越用越像你自己的风格。

## 安装

把整个 `ai-video-packaging` 文件夹（或这个 zip）拖进对话框，说：

> 帮我安装这个 skill

- **Claude Code / Claude 桌面版**：会装到 `~/.claude/skills/ai-video-packaging/`
- **Codex**：会装到 `~/.codex/skills/ai-video-packaging/`
- **WorkBuddy 等其他支持 Skill 的工具**：放进它的 skills 文件夹；不支持 Skill 的，把 `SKILL.md` 的内容作为项目说明发给它也能用

需要：Node.js 18+、ffmpeg、Chrome（AI 会帮你检查，缺什么告诉你怎么装）。剪辑软件推荐达芬奇（能脚本自动上时间线），剪映 / Premiere / Final Cut 也能用（AI 渲好素材告诉你拖到哪）。

## 怎么用

**第一步：建库**

> 用 ai-video-packaging 帮我建一个包装库。这是我最喜欢的 3 条视频：……（发链接或文件）。先帮我把里面的包装拆出来列个表。

挑你要的，让 AI 一个一个复刻；每个都会出预览，你说「要 / 改 / 不要」。先做 8 个常用的就够剪大部分口播视频。

**第二步：剪片时调用**

> 这是这期的口播稿和剪好的口播时间线，按我的包装库出一份包装清单。

清单确认后：

> 按清单把包装做出来，放到时间线上，配好音效，先给我第一分钟的检查版。
